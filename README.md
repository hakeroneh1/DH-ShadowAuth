# ShadowAuth

**ShadowAuth** — это современный плагин авторизации для Minecraft серверов (Paper/Spigot 1.21.11) с поддержкой SQLite/MySQL, капчей, комнатой авторизации и множеством настроек.

## 📋 Особенности

- 🔐 **Авторизация и регистрация** — надежная защита аккаунтов игроков
- 💾 **SQLite и MySQL** — поддержка обеих баз данных
- 🤖 **Капча** — защита от ботов (математическая и текстовая)
- 🏠 **Комната авторизации** — телепортация неавторизованных игроков в специальную зону
- 🎯 **Телепортация** — на спавн или место выхода после авторизации
- ⏱️ **Сессии** — автоматический вход в течение 15 часов
- 🧊 **Заморозка эффектов** — сохранение всех эффектов зелий до авторизации
- ⚡ **Безопасность** — блокировка действий для неавторизованных игроков
- 🎨 **Настраиваемые сообщения** — все сообщения можно изменить

## 📥 Установка

1. Скачайте последнюю версию плагина
2. Поместите `ShadowAuth.jar` в папку `plugins`
3. Перезапустите сервер
4. Настройте `config.yml` под ваши нужды

## ⚙️ Настройка

### config.yml

```yaml
settings:
  # База данных (оставьте пустым для SQLite)
  database:
    host: ""
    port: "3306"
    name: ""
    username: ""
    password: ""
  
  # Сессии (в часах)
  session:
    max_age_hours: 15
    check_ip: false
  
  # Безопасность
  security:
    max_login_attempts: 5
    attempt_timeout_minutes: 5
    password:
      min_length: 4
      max_length: 32
  
  # Комната авторизации
  auth_room:
    enabled: false
    world: "world"
    x: 0
    y: 100
    z: 0
  
  # Спавн (телепортация после авторизации)
  spawn:
    enabled: false
    world: "world"
    x: 0
    y: 100
    z: 0
  
  # Телепортация
  teleport:
    after_auth: true  # Телепортировать на место выхода
    delay: 5  # Задержка в тиках (20 тиков = 1 секунда)
  
  # Капча
  captcha:
    enabled: false
    type: "MATH"  # MATH, TEXT, BOTH
    after_attempts: 0  # Показывать после X неудачных попыток (0 = всегда)
    timeout: 60  # Время на ввод в секундах
    max_attempts: 3  # Максимум попыток
```

## 🎮 Команды

| Команда | Описание | Алиасы |
|---------|----------|--------|
| `/login <пароль>` | Войти в аккаунт | `/l` |
| `/register <пароль>` | Зарегистрировать аккаунт | `/reg` |
| `/logout` | Выйти из аккаунта | - |

## 🔧 Примеры настройки

### Включить комнату авторизации

```yaml
auth_room:
  enabled: true
  world: "world"
  x: 100.5
  y: 64
  z: 200.5
```

### Включить телепортацию на спавн после авторизации

```yaml
spawn:
  enabled: true
  world: "world"
  x: 0
  y: 100
  z: 0
```

### Включить капчу после 3 неудачных попыток

```yaml
captcha:
  enabled: true
  type: "BOTH"  # Случайный выбор между MATH и TEXT
  after_attempts: 3
  timeout: 60
  max_attempts: 3
```

### Настроить MySQL

```yaml
database:
  host: "localhost"
  port: "3306"
  name: "shadowauth"
  username: "root"
  password: "your_password"
```

## 🛡️ Безопасность

Плагин автоматически блокирует следующие действия для неавторизованных игроков:

- ❌ Движение
- ❌ Ломание/установка блоков
- ❌ Использование инвентаря
- ❌ Атака других игроков
- ❌ Использование команд (кроме `/l` и `/reg`)
- ❌ Получение урона
- ❌ Голод

  # ... и другие
